# Naibi is now Stella

Naibi was renamed Stella in version 1.2.0-beta.32: the app, the command (`stella` instead of `naibi`) and this skill. Projects with `naibi.json` keep working.

Before doing anything else, tell the user and install the new skill: download `https://raw.githubusercontent.com/lucadj77/stella/main/skill/stella/SKILL.md`, save it as a skill named `stella` next to this one (for example `skills/stella/SKILL.md`), then delete this `naibi` skill and follow the new one. If you cannot download or write files, ask the user to install the Stella skill from Stella's **AI tools…** dialog.
